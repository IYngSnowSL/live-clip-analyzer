# ADR 0004：WebUI 配置页（写入 config.local.yaml + API Key 脱敏）

- 状态：accepted
- 日期：2026-09-02
- 修订：2026-09-03 配置页字段随 ADR-0006 演变为：打轴目标时长 / ASR 引擎 / 本地模型路径 /
  字幕每行字符数 / 精切开关；原文「场景最短/最长时长、输出语言、ASR 语言」字段已不再存在

## 背景

程序的所有智能能力（视觉理解、LLM 分析、ASR 转写）都依赖外部 OpenAI 兼容 API，
用户必须配置 base_url、api_key 与三个模型名。此前只能手改配置文件或设环境变量，
对非技术用户不友好，且容易误改 `config.yaml` 导致密钥进 git。

用户提出：在 WebUI 里提供一个配置页来管理这些配置。

## 决策

1. **存储位置**：配置页写入 `config.local.yaml`（已被 gitignore），
   **不触碰** `config.yaml`。复用既有四级配置优先级，改动最小。
2. **配置范围**：AI 核心五项（base_url / api_key / 视觉 / 文本 / ASR 模型）
   + 常用参数（场景最短/最长时长、导出精切开关、输出语言、ASR 语言）。
3. **密钥安全**：`GET /api/config` 返回的 api_key 一律脱敏（前 3 + 后 4 位，短 key 全掩）；
   `PUT /api/config` 仅在传入"非掩码、非占位符"的新值时更新密钥，
   掩码值回传不会清空或改写原 key。
4. **生效方式**：无需重启。`task_runner` 每次新建任务都会重新 `load_config()`，
   保存后下一个任务即使用新配置。

## 权衡

- 环境变量（`LCA_*`）优先级仍高于配置文件：若某项被环境变量覆盖，
  配置页改动不会生效。为缓解困惑，配置页底部固定提示这一点。
- 配置页不做鉴权（本地 127.0.0.1 单用户工具）；风险边界由"默认只绑定本机"
  保证，README 明确建议不要改 `host` 为 0.0.0.0。

## 后果

- 新增 `app/api/config.py`（GET 脱敏读取 + PUT 写 local 配置）与前端设置弹窗。
- `config.yaml` 保持纯占位符；真 key 只落在 `config.local.yaml` 或环境变量，
  彻底避免密钥进入 git 历史。
- 未来"字幕驱动切分"所需的 ASR/LLM 配置复用同一配置页，无需另做入口。
